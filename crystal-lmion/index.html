クリスタル・エルミオン®

【 クリスタル・エルミオン® 】は、株式会社 Pixware の登録商標です。

ABOUT

クリスタル・エルミオン® とは

  • エルミオン・バックライト（特許 第５６８５７９０）と透明アクリル板による新しい象嵌技術を組み合わせた画期的LED電飾サインです。
  • シャープで、ハイコントラスト、精細な LED 電飾サインが低コストで実現できます。
  • 切り文字、基板、共に透明アクリル板で構成されます。
  • 薄型かつ高輝度です。
FEATURES

クリスタル・エルミオン® の特徴

01

シャープでハイ・コントラスト

従来の電飾システムで欠かすことが出来なかった支柱、枠、額縁板など、余分な背景を排し、LED発光する文字・図形に焦点を集中させるシャープでハイ・コントラストなLED電飾システムを実現します。

02

形・大きさに制約なし

LEDバックライトが組み込まれる文字・図形（発光部分）はアクリル透明版をレザー加工機で切出し構成されるため、その形、大きさに制約はなく、精細な漢字等をも電飾システムの世界に取り込むことが可能となりました。

03

”和”の世界にも最適

毛筆タッチの漢字をそのままサイン化できるなど、優雅さと華やかさを兼ね備えた”和”の世界でのLED電飾システムにも最適です。

04

カラーを自由に

カラーを自由に選ぶことができ、色彩豊かな LED 電飾サインが実現可能です。

STRUCTURE

基本構造

クリスタル・エルミオン® は電飾表示される文字・図形を象る切り文字透明アクリル板を、同じく透明アクリル板により制作されるベース基板の凹部に象嵌することにより構成されます。また、ベース基板の凹部には“逆置2重拡散方式”によるLEDが設置されます。

ASSEMBLY

構成部材と組み立て

  1. 切り文字透明アクリル板
  2. 透明アクリルベース基板
  3. 底板（バックライト）
  4. 組み立て（象嵌）

天板、底板以外は全て透明アクリル板ですが、光の全反射の原理により、光源の光が切り文字エッジ、透明アクリルベース基板から外に漏れることはありません。
